## **使用Chatgpt去生成PPT的过程**
在这里简单总结一下生成PPT的过程：我个人认为使用codex去生成PPT是对时间和额度的浪费，因为他自己的内置的有关于PPT的插件、skills都不是很好用，我甚至尝试了一下github里stars最多的作者的skills，但是还是觉得生成的效果不尽人意。所以还是用Chatgpt网页端就可以了。但是如果直接用指令或者让其他AI编辑的长提示词命令这个模型去生成PPT的话也是需要很长的时间的。所以这里我们可以参考*科研棱镜AI*作者的教程，地址是：
> https://wievf29s6ca.feishu.cn/wiki/L8mOwmm0KiApwZkfy8JcN7tonHg

我把用模型生成好的PPT放在路径：PPT/地理、技术与贸易_可编辑版.pptx里，使用之前可以用模型把这些页面变成图片后将它们作为模板。

经过多轮尝试，PPT这种东西还是自己做吧，其中的一些流程图、描述性统计什么的可以用模型做一下。因为Chatgpt在图片生成能力和对图片的理解能力方面还是具有比较优势的。今天的PPT自动化任务算是失败了，不过对这种大语言模型的理解更深了：这些大语言模型还是更擅长处理结构化、标准化的问题和工程，例如数据处理、文献解读、公式推导等。像这种对视觉和理解更深的内容目前还是有所欠缺，但是只生成一页PPT应该还是没有问题的，就是图片嘛。所以这方面暂时先不用努力了，腾出时间做别的吧。（2026年8月16日）
